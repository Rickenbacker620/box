# 维护个人最低价

这是个人维护的“已知最低价”清单，不是网上实时比价，也不是价格历史。每条记录只保存当前认可的最低价。所有价格默认以美元（USD）录入；用户提供其他币种或货币不明确时，先询问，不要擅自换算。

## 项目配置

- Supabase project ref：`rlyngocxosbmcylsxtvw`
- 前端只读；写入优先使用已连接并获授权的 Supabase 工具。
- 不索取、展示或保存 `service_role`/secret key。
- 任何用户提供的价格标签、小票或商品照片仅用于识别信息；不上传、保存或展示图片。
- 不联网搜索、核对或补全低价信息。

## 数据表：`best_prices`

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| `id` | uuid | 主键；数据库通过 `gen_random_uuid()` 自动生成 |
| `name` | text | 必填；商品名称，规格属于商品名的一部分 |
| `lowest_price` | numeric(10,2) | 必填；非负 USD 金额 |
| `unit` | text | 必填；该金额对应的计价单位 |
| `comments` | text/null | 门店、促销条件或其他备注；未提供时写 `null` |

数据库唯一约束为 `(name, unit)`。不要手动提供 `id`。

## 名称与单位规则

- `name` 表示可直接比较的商品或规格。不同包装规格必须使用不同名称，例如 `海飞丝洗发水 12 oz` 与 `海飞丝洗发水 32 oz` 是两条记录。
- 不记录品牌；除非品牌或型号是区分商品规格所必需的信息。
- 标品的单位通常是 `each` 或 `pack`：`海飞丝洗发水 12 oz` / `each`，`卫生纸 12 卷装` / `pack`。
- 非标品的单位必须是实际价格口径：`鸡胸肉` / `lb`，`生菜` / `each`。`lowest_price` 应为每该单位的价格。
- 优先使用 `each`、`pack`、`lb`、`oz`、`kg`、`g`、`roll`。没有合适单位时，先问用户是否新增单位；只有明确同意后才使用新单位。
- `comments` 优先保留门店与影响价格的条件，例如 `Costco；会员价`、`Trader Joe's；非促销价`。

## 执行流程

### 1. 收集信息

从用户消息和（如有）图片中提取：

- 商品名称
- 最低价
- 计价单位
- 备注

缺少商品名称、价格或单位时，先询问。不要从图片猜测价格、门店或促销条件；看不清时请用户补充。

### 2. 每次先读取完整清单

在任何新增、更新或回答比价问题前，必须执行 `SELECT * FROM best_prices`，读取所有现有记录。清单规模较小，不能只靠精确名称查询。

将用户商品与全部记录比较时：

- 规范化大小写、首尾空格、连字符和常见标点。
- 同时比较名称中的包装规格与 `unit`。
- 找到相似但规格或单位不同的记录时，展示候选项并询问是否是不同商品；不能合并 `12 oz` 与 `32 oz`，也不能混淆 `lb` 与 `kg`。

### 3. 新增或更新的判断

**完全匹配 `name + unit`：**

- 先展示已有价格和备注。
- 新价格更低时，询问用户确认后，更新该记录的 `lowest_price` 与 `comments`。
- 新价格相同，仅在用户要求时更新 `comments`。
- 新价格更高时，默认保留已有最低价；说明现有记录更低。只有用户明确说要用当前价格替换时，才允许更新。

**无匹配记录：**

- 展示拟新增的 `name`、`lowest_price`、`unit`、`comments`。
- 等待用户明确确认后插入一条新记录。

### 4. 写入前确认

任何写操作前，展示下表并等待明确确认：

| 项目 | 拟写入值 |
| --- | --- |
| 操作 | 新增 / 更新最低价 / 更新备注 / 用户要求替换价格 |
| 商品 | `name` |
| 最低价 | `$<lowest_price>` |
| 单位 | `unit` |
| 备注 | 原文或 `null` |

用户修改名称或单位后，重新读取全表并重新比对，再确认。

### 5. 写入与验证

用户确认后：

1. 再次 `SELECT * FROM best_prices` 并复查目标记录。
2. 新增时插入记录，让数据库生成 UUID；更新时仅更新已确认的字段。
3. 按 `id` 或 `name + unit` 重新查询，确认金额、单位和备注与确认表一致。
4. 用 publishable/anon 身份进行前端等价 `SELECT`，确认 RLS 下可读取。

最后报告新增、更新或因已有更低价格而未修改，并给出商品名、最低价、单位和备注。

## 查询最低价

回答“<商品> 最便宜多少钱、在哪里买”时：

1. 先 `SELECT * FROM best_prices`。
2. 按名称与单位匹配记录；若规格不明确，列出可选规格让用户选择。
3. 返回 `lowest_price`、`unit` 与 `comments` 中的门店/条件。
4. 明确说明结果只来自用户自己维护的清单，不代表网络或实时市场最低价。
